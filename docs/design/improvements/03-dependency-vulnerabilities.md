# Plan 03: Resolve Production Dependency Vulnerabilities

Status: complete. Implemented in commit `61bd194`.

## Objective

Remove high and critical production dependency advisories and enforce that policy in CI.

## Current Problem

`npm audit --omit=dev` reports high-severity findings through `fast-uri`, `ip-address`, and `undici`, plus moderate findings through MCP and Google Cloud dependencies.

## Dependencies

None.

## Files

- Modify `package.json` and `package-lock.json` using npm commands.
- Modify affected adapter or MCP source only when an upgrade changes an API.
- Modify `.github/workflows/ci.yml`.
- Update the baseline in `docs/design/security-performance-ergonomics-plan.md`.

## Locked Decisions

- Do not use `npm audit fix --force`.
- Do not add package overrides until direct dependency upgrades have been attempted.
- A temporary override requires a comment in the implementation PR explaining the upstream issue and removal condition.
- CI blocks high and critical production findings. Moderate findings remain visible but do not block this plan.

## Implementation Steps

1. Save `npm audit --omit=dev --json` output outside the repository and map each advisory to its direct dependency.
2. Check current releases of `@modelcontextprotocol/sdk`, `@google-cloud/storage`, Effect packages, and cloud SDK clients.
3. Upgrade one direct dependency family at a time with `npm install <package>@<version>`.
4. After each family, run typecheck and its focused tests before proceeding.
5. If an API changed, make the smallest source adaptation and add a regression test for that behavior.
6. Run the complete unit and integration suites after all upgrades.
7. Add a CI command that fails only for high or critical production vulnerabilities.
8. Record any remaining moderate advisories with package owner and expected remediation.

## Required Tests

- MCP transport tests after MCP SDK upgrades.
- GCS adapter tests after Google Cloud upgrades.
- Driver tests after AWS SDK upgrades.
- Existing package build and integration tests.

## Acceptance Criteria

- `npm audit --omit=dev --audit-level=high` exits successfully.
- The lockfile is generated by npm and contains no manual edits.
- CI enforces the same audit threshold.
- All existing checks pass.

## Non-Goals

- Eliminating every moderate advisory with risky downgrades.
- Migrating package managers.
- Updating unrelated dependencies solely for freshness.

## Verification

```bash
npm run check
npm run build
npm run test:integration
npm audit --omit=dev --audit-level=high
```
